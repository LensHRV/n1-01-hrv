# N1 HRV Diagnosis — Blog Materials

These are the materials I used to create the blog **"4 Findings from 4 Days of Tracking: An HRV Case Study"** at [https://lenshrv.com/blog/4-findings-from-4-days-of-tracking](https://lenshrv.com/blog/4-findings-from-4-days-of-tracking).

## Data (registered by the user)

- `diet_compat.csv` — meal log with `datetime_cdmx` (`%Y-%m-%d %H:%M`) compatible with HRV.
- `hrv_metrics_tagged.csv` — 4-day HRV self-tracking (`datetime_cdmx, tag, bpm, rmssd, hf, lf, stressIndex, ...`).
- `lenshrv_database.zip` — reference database (renamed from `experiment.zip`).

## Code (generated by AI from the user's data)

Python code was generated by **Muse Spark 1.3 Free High using OpenCode**, based on the data registered by the user.

- `01_smoking_night_curve.py` → `fig1_smoking_night_curve.png` (3-stage night curve on stressIndex)
- `02_food_vagal_cost.py` → `food_meal_deltas.csv` + `fig2_food_vagal_cost.png` (meal deltas ±2h + HF trend)
- `03_gym_parasympathetic_rebound.py` → `fig3_gym_rebound.png` (post-workout HF rebound curve)


Requires the project `.venv` (uv, pandas, matplotlib).
